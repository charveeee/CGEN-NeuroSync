CGEN Glossary

Algorithmic definitions and biological signal tracking explanations.

Beta/Alpha Ratio

A numerical index calculating active task engagement versus relative cognitive fatigue. A higher ratio indicates intense mental focus or situational stress, while a dropping ratio suggests a shift into relaxation or cognitive exhaustion.

Fused Load Index

A single score that measures your mental stress level in real time. It works by combining brainwave patterns and where/how your eyes are moving on screen.

Adaptive Baseline

A dynamically recalculating threshold based on historical user performance. Rather than relying on static limits, the system dynamically adjusts stress and focus triggers to fit the user's natural personal baseline over time.

Adaptive, Fused-State Classification & Intervention

This is the core algorithmic decision model. It continuously evaluates fused biometric data against the adaptive baseline to automatically categorize state levels (Optimal Focus, Moderate Elevation, Critical Overload) and dynamically trigger UI adjustments and logging.

Continuous Biometric Telemetry

The underlying processing engine. To remain fully accessible without requiring physical hardware, the system streams verified PhysioNet data or live webcam feeds through a mathematical simulation matrix to drive real-time dashboard visualizers.
